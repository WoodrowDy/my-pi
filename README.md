# my-pi

[Pi](https://pi.dev) 에이전트에서 쓰는 개인 스킬 모음입니다.
여러 PC에서 같은 스킬을 쓰려고 레포 하나를 Pi 패키지로 설치해 둡니다.

## 설치

```bash
pi install git:https://github.com/WoodrowDy/my-pi
```

## 스킬

| 스킬 | 하는 일 |
|---|---|
| [jira-ticket-format](skills/jira-ticket-format/SKILL.md) | 회의 메모·설계 문서·작업 기록을 정해진 서식의 지라 티켓 본문으로 정리 |
